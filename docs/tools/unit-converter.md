## 支持的换算类别

| 类别 | 单位示例 |
|------|---------|
| 长度 | 微米、mm、cm、m、km、英寸、英尺、码、英里、海里 |
| 重量 | mg、g、kg、吨、磅、盎司、斤、英石 |
| 面积 | mm²、cm²、m²、km²、平方英寸、平方英尺、公顷、英亩、亩、坪 |
| 体积 | mL、cm³、L、m³、液量盎司、汤匙、茶匙、杯、品脱、加仑（美制） |
| 温度 | 摄氏度、华氏度、开尔文 |
| 数据存储 | bit、B；KB/MB/GB/TB（二进制 1024）；kB/MB/GB（SI 十进制 1000） |
| 速度 | m/s、km/h、mph、ft/s、节 |
| 压强 | Pa、hPa、kPa、MPa、bar、atm、mmHg、psi |
| 能量 | J、kJ、MJ、cal、kcal、Wh、kWh、eV |
| 功率 | mW、W、kW、MW、美制马力 hp、公制马力 PS |
| 频率 | Hz、kHz、MHz、GHz、rpm（转/分，与 Hz 按 1 Hz = 60 rpm） |
| 角度 | rad、°、turn、角分、角秒、梯度 (gon) |
| 时间 | ns、µs、ms、s、min、h、日、周、儒略年 |

## 功能特点

- **分类标签**：点击顶部分类切换换算类别
- **实时结果**：选择源单位和目标单位后实时显示结果
- **全量展示**：底部网格展示该类别所有单位的换算结果
- **科学计数法**：极大或极小数值自动切换为科学计数法显示

## 已知限制

- 温度换算不基于乘法因子，而是通过公式转换，属特殊处理
- **数据存储**：同一类别内同时提供「二进制（1024）」与「SI 十进制（1000）」字节单位，请注意与操作系统、硬盘标称可能存在的差异
- **体积**：液量单位默认为 **美制 (US)**；**马力**：美制 hp 与公制 PS 定义不同
- **时间**：「儒略年」按 365.25 日计算，与历法年不完全一致
