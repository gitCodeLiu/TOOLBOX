# ITERATION-005：JSON 格式化折叠预览与布局交互优化

**迭代时间**：2026-05-08
**迭代类型**：功能增强
**影响范围**：`json-formatter` 工具页、工具文档、迭代规范

---

## 背景与目标
> JSON 格式化工具在连续优化过程中，先后完成了可折叠预览、纵向铺满布局和长内容场景按钮可达性优化。为避免同一天产生过多碎片迭代记录，本次按“按天聚合”规则整合为单条迭代。

## 新增 / 修改内容
- 新增 JSON 树形预览，支持对象与数组节点逐级折叠/展开
- 新增「全部折叠」「全部展开」控制，提升大 JSON 浏览效率
- 输出区改为纵向自适应布局，支持在桌面端尽量铺满可视高度
- 操作按钮改为底部粘性悬浮工具栏，避免长内容将按钮顶出可视区域
- 保留并兼容格式化、压缩、校验、键名排序、一键复制等既有能力
- 更新迭代规则为“按天聚合”，同日多次优化统一记录

## 注意事项
> 折叠预览仅面向合法 JSON；输入非法时只展示错误信息。粘性工具栏为保证可达性会覆盖底部部分视觉区域，已通过内容底部留白规避遮挡。

## 后续优化
> 可增加节点搜索（JSONPath）、超大数据虚拟渲染、输出区全屏模式，进一步提升深层数据浏览体验。
